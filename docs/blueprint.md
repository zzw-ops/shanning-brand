# **App Name**: 山宁 Shanning | 东方茶饮新美学

## Core Features:

- 四季草本智慧选茶 Tool: 基于 generative AI，用户输入当下情绪或当日气候，工具自动推荐最适配的季节限定草本配方与“轻养生”饮品方案。
- 全息菜单展示: 以视差滚动呈现春、夏、秋、冬四个产品系列的成分与设计理念，强调 0 添加与东方药食同源的美学。
- 市场潜力交互看板: 以可视化数据卡片展示澳门市场茶饮空白点，辅助黑客松现场路演中的竞品对比分析。
- 线上联名运营矩阵: 内置社交媒体样板生成器，展示在小红书与 Instagram 等平台的内容投放逻辑与 KOL 联动效果预览。
- 多终端体验自适应: 专为手机、平板与网页端优化的全端自适应响应式布局，满足移动办公与线下演示需求。
- 线下店选址空间导向: 通过空间氛围交互模块展示门店视觉识别系统 (VI)，包括东方植物美学样机设计与门店选址推荐。

## Style Guidelines:

- Primary color: 深墨绿 (#22332B)，传达天然药本的沉稳感与高端定位。
- Background color: 米白/绢纸色 (#F7F4F0)，通过高度去饱和色模拟中式纸张的质感，保持呼吸感。
- Accent color: 桂花金 (#CC9B4D)，作为 CTA 按钮与亮点元素，提供低调的华丽感。
- 采用 'Playfair Display' 作为英文及数字装饰性字体（具有优雅时尚的对比度），正文推荐使用 'PT Sans'（温潤而中立，适合移动端快速阅读）。
- 使用手绘感、细线条的草本植物线稿（人参、陈皮、桂花），强调天然原始素材而非医疗药房感。
- 采用极简栅格系统与大面积留白，模仿画卷式左右跨度的非平衡设计，打破传统布局的死板。
- 当鼠标划过产品卡片或点击菜单时，伴随流畅的淡入与微小位移（Translate Y-10px），传达禅意、自然的宁静氛围。
